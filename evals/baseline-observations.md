# Baseline observations

Before implementation there is no executable Scenic Magnet skill, prompt compiler, or analyzer. The reference examples demonstrate a useful extraction idea but also expose the failure modes this project must avoid:

- badge-like single-object reduction instead of a multi-element micro-landscape;
- fixed cloth backgrounds rather than scene-matched tactile materials;
- mechanisms treated as decoration instead of scene-supported structure;
- flat enamel graphics with weak thickness and contact shadow;
- invented or guessed captions;
- composite before/after presentation instead of a standalone 4:3 result.

The first automated contract run is expected to fail because `compile_magnet_brief.py` does not yet exist.
