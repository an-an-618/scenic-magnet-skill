# 景铸 · Scenic Magnet — Skill 设计说明

状态：已确认，进入实施  
日期：2026-08-26  
仓库名：`scenic-magnet-skill`  
Skill 调用名：`$scenic-magnet-v1`

## 1. 产品定义

景铸将用户提供的照片直接重构为一张 4:3 横向产品摄影图：照片中的核心景观被浓缩成一枚具有真实金属厚度、珐琅色彩与多层浮雕的精致冰箱贴，并陈列在一块由原图主色与场景语义共同决定的单一材质背景上。

它不是单物体徽章、照片抠图贴纸、原图缩小版，也不是上下分屏的 Before/After 海报。它提炼照片的“场景身份”，以 2–5 个共同定义该场景的元素重组为可生产、可收藏的微缩景观。机关不是必备；只有场景天然包含旋转、开合、滑动或抽拉语义时才加入一个克制而可信的互动结构。

核心命题：

```text
把一段真实景观，铸成一枚可以带回家的立体纪念物。
```

## 2. 目标与非目标

### 目标

- 用户上传一张照片后直接输出一张 4:3 横向成品，不提供候选、不等待确认。
- 自动提炼 2–5 个共同定义场景的核心元素，而非寻找唯一主体。
- 保留原场景的身份、空间关系、关键色彩与不可替代结构。
- 自动选择开放式、场景派生的冰箱贴外轮廓，避免统一圆形或盾形徽章。
- 自动选择最多两种金属色与受控珐琅系统，表现真实厚度、倒角、铸造细纹、高光与接触阴影。
- 从原图占比最大的主色提取背景色，并根据场景语义选择一种安静的实体材质。
- 仅在语义自然时设计一个互动机关；复杂场景最多两个。
- 使用轻微俯视的 3/4 产品摄影视角；严格对称场景可接近正视。
- 对画幅、冰箱贴占比、视觉完整性和明显生成失败进行可重复检查。

### 非目标

- 不输出原图与成品的上下或左右对照。
- 不把照片连续贴在冰箱贴表面，也不生成平面印刷贴纸。
- 不将所有场景统一做成圆形徽章、纪念章或钥匙扣。
- 不强制每张图包含互动机关。
- 不凭空添加地点、日期、标题、作者名、水印或伪品牌。
- 不为了丰富画面添加原图中不存在的著名地标、人物或交通工具。
- 不使用手持展示、冰箱门实拍、多枚磁贴组合或与主题无关的道具。

## 3. 核心交互

```text
用户上传照片并调用 Skill
  → 分析场景身份、视觉层级、主色和可制造性
  → 自动建立 Scene DNA Card
  → 选择 2–5 个核心景观元素
  → 自动确定金属、珐琅、外轮廓、层级和可选机关
  → 自动确定单一背景材质与主色
  → 编译可见像素指令
  → 生成一张 4:3 成品
  → 正常尺寸与缩略图检查
  → 必要时最多定向修正一次
  → 直接展示最终结果与一句简短设计说明
```

用户不需要选择方案，也不需要确认背景、金属或机关。Skill 应在内部完成这些判断，不公开冗长分析过程。

## 4. Scene DNA Card

生成前在内部建立一张 Scene DNA Card：

- 场景类型：城市、建筑、交通、海岸、山林、室内、食物或混合场景；
- 场景身份句：用一句话描述移除后会令照片失去身份的关系；
- 空间基座：街道、岩岸、山脊、水线、站台、桌面或建筑底座；
- 主地标：最能识别场景的建筑、交通工具、自然结构或组合；
- 辅助意象：0–3 个强化场景身份的元素；
- 删除项：普通路人、杂物、重复建筑、无意义纹理与遮挡；
- 主色：原图面积最大的有效色彩及其明度、饱和度范围；
- 材质暗示：纸、丝、毛毡、瓦楞、压纹板或其他实体材料；
- 金属温度：暖、冷或中性；
- 机关语义：旋转、开合、滑动、抽拉或无；
- 文字来源：用户提供、原图清晰招牌或无。

## 5. 景观浓缩系统

### 5.1 核心元素

- 最终使用 2–5 个元素共同构成微缩景观。
- 通常包含一个空间基座、一个主地标和 0–3 个辅助意象。
- 允许调整相对比例、重叠和前后层级，以适应冰箱贴的可读性与制造逻辑。
- 必须保留场景身份和关键空间关系，不得凭空替换成更著名的地标。
- 普通路人与杂物默认删除。
- 人物只有在动作或关系不可替代时才保留，并转为很小的珐琅剪影，不生成可辨认肖像。

### 5.2 外轮廓

- 优先沿建筑天际线、山线、车体、岸线、拱门或街景结构自然生长。
- 可以使用局部金属框架稳定结构，但框架不得压过景观本身。
- 避免默认圆形、椭圆形、盾牌形、邮票形和规则徽章底板。
- 外轮廓需要在缩略图尺度下清楚，并具备真实可制造的连续连接。

### 5.3 层级与制造感

- 使用前景、中景、后景三层以内的浮雕关系。
- 主地标为最高层，辅助意象降低 15%–40% 的视觉高度。
- 金属边必须连续，不能出现漂浮碎片或无法连接的孤岛。
- 细节需要符合铸造、珐琅或冲压工艺的最小线宽，不追求微型照片级纹理。

## 6. 材质系统

### 6.1 金属与珐琅

- 暖色、历史街景：黄铜、古金、暖珐琅。
- 海岸、现代建筑、清冷天空：银、镍、冷白珐琅。
- 山林、工业、夜景：枪灰、氧化铜、局部做旧。
- 同一枚冰箱贴最多使用两种金属色。
- 彩色部分使用实色或半透明珐琅，保留受控的源照片色彩关系。
- 必须表现 2–5 mm 的视觉厚度、倒角、铸造细纹、边缘高光、局部反射与柔和接触阴影。
- 避免塑料玩具感、全镜面金属、廉价闪粉、过度 HDR 与纯平矢量效果。

### 6.2 背景

- 背景色从原图占比最大的有效主色派生。
- 允许为了衬托冰箱贴而降低明度或饱和度，但不得替换成无关品牌色。
- 每张只选择一种主要材质：细纹纸、瓦楞纸、丝绸、毛毡、压纹板、织物或其他合适实体材料。
- 城市和建筑优先细纹纸、压纹板或织物；海岸优先丝绸或细密织物；山林优先毛毡；工业场景优先瓦楞纸或压纹板。
- 背景纹理必须真实可见但保持安静，不可成为第二主角。

## 7. 机关系统

机关是可选分支，不是完成度指标。

- 日月、摩天轮、风车、船舵：可旋转。
- 门窗、书页、招牌：可开合。
- 电车、缆车、船、人物路径：可滑动。
- 多层景深、地图或隐藏空间：可抽拉。
- 不存在自然语义时：无机关。

规则：

- 默认最多一个机关；只有复杂场景且结构清楚时允许两个。
- 机关必须拥有可见的轴、铰链、滑轨或抽拉槽，不能只靠文字声称可互动。
- 静态成品应通过结构、轻微错位或运动止点暗示可操作性，不使用夸张运动线。
- 机关不得遮挡主地标，也不得让冰箱贴看起来像玩具模型或机械拼装包。

## 8. 文字策略

- 默认不添加任何文字。
- 用户提供准确文字时，可将其做成小型金属铭牌、珐琅字或结构性招牌。
- 原图中只有清晰可辨、且属于场景身份的文字才允许保留。
- 无法准确辨认时宁可省略，不猜测、不补全、不翻译。
- 不添加地点说明、作者名、社交媒体账号、水印、日期或产品编号。

## 9. 4:3 产品摄影

- 输出固定为 4:3 横向画幅。
- 只展示一枚完整冰箱贴与一块单一材质背景，不出现原图对照。
- 冰箱贴占画面面积建议为 45%–65%，四周保留足够呼吸空间。
- 默认轻微俯视的 3/4 视角；严格对称构图可接近正视。
- 使用柔和侧上方主光、克制补光和清晰但不过黑的接触阴影。
- 景深轻微，冰箱贴整体必须清晰；背景纹理可柔化但不可糊成纯色。
- 不出现手、包装盒、支架、冰箱门、多枚磁贴或装饰散物。

## 10. Prompt 编译器

最终编辑提示词只描述可见像素结果，分为六段：

1. 4:3 产品摄影画幅、单枚冰箱贴和源照片身份锁定；
2. Scene DNA 的核心元素、层级、外轮廓和必须删除的内容；
3. 金属、珐琅、厚度、倒角、浮雕、光泽与制造约束；
4. 可选机关的结构与静态可见证据，或明确无机关；
5. 主色派生的单一材质背景、视角、灯光和阴影；
6. 文字规则与硬性禁止项。

不得把内部分析分数、文件路径、设计理论或候选方案写入生成提示词。修正提示必须重复场景身份、核心元素和文字约束。

## 11. 质量门

### 11.1 生成前

- 已建立 Scene DNA Card；
- 核心元素数量为 2–5；
- 场景身份没有被单一物体替代；
- 背景色来自原图有效主色；
- 背景只使用一种主要材质；
- 金属色不超过两种；
- 机关有自然语义，或明确无机关；
- 没有未经授权的文字；
- Prompt 明确禁止原图对照、徽章底板和平面贴纸。

### 11.2 正常尺寸检查

- 主地标、空间基座与辅助意象均可辨认；
- 金属边缘连续，浮雕层级和厚度可信；
- 珐琅颜色没有溢出金属隔线；
- 机关拥有可见且合理的结构；
- 文字准确，或画面完全无字；
- 没有复制、扭曲或错误拼接的建筑与人物。

### 11.3 缩略图检查

- 4:3 横向画幅成立；
- 冰箱贴是唯一视觉主角，占比约 45%–65%；
- 外轮廓不是统一圆形徽章；
- 微缩景观在小尺寸仍能读出场景身份；
- 背景主色和材质成立但不抢眼；
- 金属高光、厚度和接触阴影共同提供立体感；
- 不像塑料玩具、平面贴纸、照片抠图或旅游徽章。

### 11.4 定向修正

最多自动修正一次，只针对已观察到的失败：

- 场景身份丢失：恢复缺失的关键关系，不增加无关元素；
- 过度徽章化：移除规则底板，恢复场景派生轮廓；
- 过平：加强厚度、倒角、浮雕层级和接触阴影；
- 塑料感：降低高饱和塑料反光，恢复金属与珐琅材质；
- 背景抢眼：降低纹理对比、明度或饱和度；
- 机关牵强：删除机关并修复连续结构；
- 文字错误：删除错误文字，不自行改写。

第二次仍失败时应诚实展示当前结果并指出失败，不得继续漂移式重生成。

- 用户照片只用于当前请求。
- 未经逐张明确授权，不得上传、提交、复制进仓库或用作公开 showcase。
- 本地测试授权不等于公开发布授权。
- 不公开完整生成提示词，除非用户明确要求。
- 最终只展示处理结果和简短设计说明，不暴露内部 Scene DNA Card。

## 14. 验收标准

- 调用 `$scenic-magnet-v1` 并上传照片后，无需候选即可得到一张 4:3 横向成品。
- 成品只包含单枚金属微缩景观冰箱贴与单一材质背景。
- 冰箱贴包含 2–5 个定义场景的元素，并保持原场景身份。
- 金属、珐琅、厚度、浮雕与阴影在正常尺寸和缩略图都可信。
- 背景颜色可追溯到原图主色，材质可辨但不抢眼。
- 机关只在自然语义下出现，文字不被猜测或编造。
- 自动检查与最多一次定向修正可稳定执行。
