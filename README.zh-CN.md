# 景铸 · Scenic Magnet

将用户提供的照片直接转化为一张 4:3 横向产品摄影：原场景被浓缩成具有铸造厚度、金属光泽和立体层次的微缩景观冰箱贴。

景铸不会把整张照片缩小后塞进徽章，也不会固定套用圆形、盾牌或相框。它先读取场景的空间 DNA，从原图中保留 2–5 个最能承载地点身份的元素，再把这些元素重新连接成具有前、中、后景浮雕层次的一个完整金属物件。背景只使用一种由原图最大有效颜色推导出的安静材质。

## 它会生成什么

- 一张直接完成的 4:3 横图，不提供候选，也不设置确认轮次。
- 一个由原场景轮廓推导出的连体微缩景观，而不是默认的硬币、盾牌或平面牌匾。
- 可见的铸造厚度、倒角、高低浮雕、珐琅凹槽、克制的金属高光和真实接触阴影。
- 一种与场景匹配的触感背景，例如丝绸纸、毛毡、瓦楞艺术纸、织纹纸、亚麻纸或博物馆卡纸。
- 只有场景本身存在运动或揭示语义时，才加入一个可旋转、滑动、开合或抽拉的机关。
- 默认无字；只有用户明确给出的准确文字，或原图中清晰且承担地点身份的短文字可以保留。

## 工作方式

```text
照片
→ 读取 Scene DNA
→ 选择2–5个相互连接的身份元素
→ 确定一种主色材质与一组金属体系
→ 根据场景决定是否需要一个机关
→ 直接生成一张4:3产品图
→ 以正常尺寸和缩略图双重检查
→ 最多修正一个已观察到的问题
```

原图始终是事实来源。Skill 可以简化、合并或删除细节，但不能发明地标、地点名称、交通工具、建筑或人物肖像。

## 本地安装

从当前仓库复制可安装 Skill：

```bash
mkdir -p ~/.codex/skills
cp -R skills/scenic-magnet-v1 ~/.codex/skills/
```

如果 Skill 没有立即出现，请重启 Codex。

可选的画面检测脚本依赖 Pillow。环境没有 Pillow 时仍可进行视觉质检，但不得在用户任务中静默安装依赖。

## 使用

上传照片后调用：

```text
用 $scenic-magnet-v1 把这张照片做成金属微缩景观冰箱贴。
```

Skill 会直接返回完成预览，不会要求用户从多个候选方案中选择。
